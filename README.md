## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/malar172/portfolio1.git
   ```

2. Go to the project folder:

   ```bash
   cd portfolio1
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser.
